Le conté a un amigo que hace fotografía de paisajes sobre un sitio que encontré para subir las visualizaciones de sus álbumes en Flickr, porque sabía que llevaba tiempo quejándose de lo poco que le veían sus publicaciones. Le pasé el enlace https://es.mrpopular.net/?category=socialnetworks&type=Flickr&service=views y terminó probándolo esa misma semana. Lo que más destacó fue la variedad de opciones de calidad disponibles, algo que no había visto en otros lugares, además de precios que no le rompieron el bolsillo. También mencionó que todo comenzó muy rápido, sin tener que esperar mucho para ver resultados, y que la garantía incluida le dio tranquilidad por si algo salía mal. Ahora dice que piensa seguir usándolo para sus próximos proyectos, y la verdad después de ver cómo le fue, yo también lo voy a proba
